# Legal And Usage

MediaForge + CueBot is intended for local-first, portfolio-safe media preparation and Discord playback.

CueBot starts with uploaded or user-provided media. Users are responsible for only uploading media they have the right to use in their server context.

CueBot 0.2 may search open or licensed music providers. Provider integrations should preserve license, attribution, and source page metadata whenever available.

CueBot 1.0 may support MediaForge URL playback for legally permitted media. URL support should be limited to approved sources and should not bypass access controls, copy protection, platform restrictions, or rights-holder terms.

MediaForge is a personal local converter. It should prepare local media files for lawful personal workflows.

Do not frame, document, or market this project as a YouTube downloader, piracy tool, or mechanism for extracting restricted media.
