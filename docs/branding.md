# Branding

## Names

- Bot name: CueBot
- Project name: MediaForge + CueBot

Developers may name their private Discord test application `CueBot Dev` while testing locally, but public-facing docs and demo materials should refer to the bot as `CueBot`.

## Logo Concept

- Circular Discord avatar.
- Dark navy/charcoal background.
- Cyan and purple accent.
- Music note merged with a play button.
- Subtle queue/sound-wave motif.
- No text.
- Readable at small Discord avatar size.
- Clean vector/app icon style.

Suggested files:

- `assets/cuebot-avatar.png`
- `assets/cuebot-avatar.svg`
- `assets/cuebot-logo.svg`

## Suggested Discord Description

```text
CueBot is a Discord music bot powered by MediaForge, supporting uploaded files, direct URLs, YouTube search, queue controls, and local-first media preparation.
```
