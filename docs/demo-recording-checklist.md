# Demo Recording Checklist

Record a short demo GIF or video after the bot is running in your private Discord test server.

## Suggested Length

45 to 90 seconds.

## Shot List

1. Show CueBot online in the Discord member list.
2. Run `/ping` and show the visible response.
3. Join a voice channel.
4. Run `/play attachment:<small mp3>` or `/search query:<text>` and click a Play button.
5. Show the bot joining voice and playback starting.
6. Run `/nowplaying`.
7. Run `/pause` and `/resume`.
8. Run `/queue`.
9. Run `/stop` and show the bot disconnecting.

## Capture Notes

- Hide tokens, `.env`, private channels, private DMs, and server invite links.
- Keep the PowerShell window visible for a few seconds to show safe logs.
- Save the final file as `docs/screenshots/cuebot-demo.gif` or `docs/screenshots/cuebot-demo.mp4`.

## README Embed

After recording, add the file to the README demo section.
